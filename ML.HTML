★ COMO UMA MÁQUINA APRENDE? ★

O computador recebe dados e procura padrões e relações entre eles.

Depois do treinamento, ele utiliza esses padrões para analisar novos dados.

★ EXEMPLOS ★

• YouTube: recomenda vídeos

• Spotify: recomenda músicas

• E-mail: identifica spam

• Celular: reconhece voz e imagens

★ TERMOS IMPORTANTES ★

Dados: informações usadas para o aprendizado.

Algoritmo: método usado para encontrar padrões.

Modelo: resultado do treinamento.

O QUE É MACHINE LEARNING?

Machine Learning é uma área da Inteligência Artificial que permite aos computadores aprender padrões através de dados e realizar previsões.

COMO FUNCIONA?

O sistema recebe dados, encontra padrões e cria um modelo capaz de analisar novos dados e gerar resultados.

DADOS → TREINAMENTO → MODELO → RESULTADO

TIPOS DE MACHINE LEARNING

Supervisionado: aprende com respostas conhecidas.

Não supervisionado: encontra padrões nos dados.

Semi-supervisionado: combina os dois métodos.

Reforço: aprende através de recompensas e penalidades.

ONDE É UTILIZADO?

Machine Learning aparece em recomendações de vídeos, músicas e produtos, filtros de spam, reconhecimento de voz e imagens e mecanismos de busca.

IA × MACHINE LEARNING

Inteligência Artificial é o campo geral. Machine Learning é uma área da IA que utiliza dados para aprender padrões.

DEEP LEARNING

Deep Learning utiliza redes neurais com várias camadas para resolver tarefas mais complexas, como reconhecimento de imagens, voz e linguagem.

PROGRAMAÇÃO

Programação, matemática e estatística são importantes. Python é uma das linguagens mais utilizadas na área.
